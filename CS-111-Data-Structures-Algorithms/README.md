# CS 111: Data Structures, Algorithms & Computational Thinking

## Course Overview

This repository contains lecture presentations, PDF documents,
and supplementary learning resources for CS 111: Data Structures,
Algorithms & Computational Thinking.

The course introduces fundamental data structures,
algorithmic problem-solving techniques, computational thinking,
and the principles of designing efficient algorithms.

## Course Topics

### 1. Introduction to Computational Thinking
- Fundamentals of Computational Thinking
- Problem Decomposition
- Pattern Recognition
- Abstraction
- Algorithmic Thinking

### 2. Introduction to Algorithms
- Definition and Characteristics of Algorithms
- Algorithm Design Techniques
- Pseudocode and Flowcharts
- Problem-Solving Strategies

### 3. Fundamental Data Structures
- Arrays
- Linked Lists
- Stacks
- Queues
- Hash Tables

### 4. Advanced Data Structures
- Trees and Binary Trees
- Binary Search Trees
- Heaps
- Graphs

### 5. Searching and Sorting Algorithms
- Linear Search
- Binary Search
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

### 6. Algorithm Analysis
- Time Complexity
- Space Complexity
- Asymptotic Analysis
- Big O Notation
- Best, Average, and Worst-Case Analysis

### 7. Algorithm Design
- Divide and Conquer
- Greedy Algorithms
- Recursion
- Dynamic Programming
- Backtracking

## Lecture Materials

This directory contains PDF lecture presentations,
course notes, examples, and supplementary reference materials.

## Learning Objectives

Students should be able to:

- Understand fundamental data structures and their applications.
- Select appropriate data structures for different problems.
- Design and implement basic algorithms.
- Apply computational thinking to solve problems.
- Analyse algorithm efficiency using time and space complexity.
- Compare different algorithmic approaches.
- Understand fundamental algorithm design techniques.
