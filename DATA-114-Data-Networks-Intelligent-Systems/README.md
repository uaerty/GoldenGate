# DATA 114: Data Networks & Intelligent Systems

## Course Overview

This repository contains lecture presentations, PDF documents,
and supplementary learning resources for DATA 114: Data Networks
& Intelligent Systems.

The course introduces fundamental networking concepts,
data communication principles, network architectures,
communication protocols, and intelligent systems.

## Course Topics

### 1. Fundamentals of Data Networks
- Introduction to Computer Networks
- Network Components and Classifications
- Network Topologies
- LAN, MAN, and WAN
- Network Models and Architectures

### 2. Data Communications
- Fundamentals of Data Communication
- Transmission Media
- Data Transmission Techniques
- Switching Techniques
- Communication Channels

### 3. Network Models and Protocols
- OSI Reference Model
- TCP/IP Protocol Suite
- Network Layer and Transport Layer
- IP Addressing and Routing
- Application Layer Protocols

### 4. Network Technologies
- Ethernet and Wireless Networks
- Internet Technologies
- Network Security Fundamentals
- Network Performance and Reliability

### 5. Intelligent Systems
- Introduction to Intelligent Systems
- Artificial Intelligence Fundamentals
- Intelligent Network Applications
- Emerging Network Technologies

## Lecture Materials

This directory contains PDF lecture presentations,
course notes, and relevant reference materials.

## Learning Objectives

Students should be able to:

- Explain fundamental data networking concepts.
- Understand communication models and protocols.
- Describe network architectures and technologies.
- Analyse basic networking problems.
- Understand the role of intelligent systems
  in modern networking environments.
