# Golden Gate University – Academic Teaching Resources

Welcome to the academic teaching resources repository for
Golden Gate University (GGU).

This repository serves as a centralised collection of lecture
presentations, course materials, reference documents, and
supplementary learning resources for undergraduate computing
and information technology courses.

## Courses

### 1. DATA 114: Data Networks & Intelligent Systems

Study materials covering computer networks, data communications,
network architectures, protocols, and intelligent systems.

[Explore DATA 114 Materials](./DATA-114-Data-Networks-Intelligent-Systems/)

### 2. CS 117: Systems & Architecture
(Hardware + OS Integration)

Study materials covering computer systems architecture,
computer organisation, hardware components, operating systems,
and hardware-software integration.

[Explore CS 117 Materials](./CS-117-Systems-and-Architecture/)

### 3. CS 111: Data Structures, Algorithms &
Computational Thinking

Study materials covering fundamental data structures,
algorithm design, computational problem-solving, and
algorithm analysis.

[Explore CS 111 Materials](./CS-111-Data-Structures-Algorithms/)

## Repository Structure

- `DATA-114-Data-Networks-Intelligent-Systems/`
- `CS-117-Systems-and-Architecture/`
- `CS-111-Data-Structures-Algorithms/`

Each course directory contains its respective lecture
presentations, PDF documents, and supplementary resources.

## Learning Resources

The repository is intended to support:

- Lecture preparation and delivery.
- Access to course-related learning materials.
- Conceptual understanding through structured resources.
- Independent study and revision.
- Academic reference and knowledge sharing.
