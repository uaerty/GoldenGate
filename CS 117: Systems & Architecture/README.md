# CS 117: Systems & Architecture
## Hardware + OS Integration

## Course Overview

This repository contains lecture presentations, PDF documents,
and supplementary learning resources for CS 117: Systems &
Architecture.

The course explores the fundamental concepts of computer
systems, hardware architecture, computer organisation,
operating systems, and the interaction between hardware
and software components.

## Course Topics

### 1. Introduction to Computer Systems
- Fundamentals of Computer Systems
- Computer Hardware and Software
- Functional Components of a Computer
- Computer System Organisation

### 2. Digital Foundations
- Number Systems and Binary Arithmetic
- Boolean Algebra and Logic Gates
- Digital Logic Circuits
- Data Representation

### 3. Computer Architecture
- CPU Architecture and Components
- Arithmetic Logic Unit (ALU)
- Control Unit
- Registers and Instruction Execution
- Instruction Set Architecture

### 4. Memory Organisation
- Primary and Secondary Memory
- Cache Memory
- Memory Hierarchy
- Virtual Memory
- Memory Management Fundamentals

### 5. Operating Systems
- Introduction to Operating Systems
- Process and Thread Management
- CPU Scheduling
- Memory Management
- File Systems
- Input/Output Management

### 6. Hardware and OS Integration
- Hardware-Software Interaction
- Interrupts and System Calls
- Device Management
- System Resource Management
- Computer System Performance

## Lecture Materials

This directory contains PDF lecture presentations,
course notes, and supplementary reference materials.

## Learning Objectives

Students should be able to:

- Understand computer hardware components and architecture.
- Explain CPU operations and instruction execution.
- Understand memory organisation and hierarchy.
- Describe fundamental operating system concepts.
- Explain the interaction between hardware and operating systems.
- Understand system resource management.
